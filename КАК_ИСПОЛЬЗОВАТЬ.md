# Как пользоваться Text2SQL

## Самый простой запуск на Mac — без браузера

1. Убедитесь, что Docker Desktop установлен. Запускать контейнеры вручную не нужно.
2. Откройте папку `Text2SQL` в Finder.
3. Дважды нажмите файл **`START_TEXT2SQL.command`**.
4. При первом запуске подождите несколько минут. Программа сама установит компоненты, запустит пять баз и откроет обычное окно Text2SQL. Браузер не используется.
5. Не закрывайте появившееся окно Terminal, пока пользуетесь приложением.

Если macOS впервые спросит разрешение: нажмите правой кнопкой по `START_TEXT2SQL.command` → **Открыть** → ещё раз **Открыть**.

## Запуск прямо из VS Code

1. В VS Code нажмите **File → Open Workspace from File…**.
2. Выберите файл `Text2SQL.code-workspace` из папки проекта.
3. Нажмите **Terminal → Run Task…**.
4. Выберите **Text2SQL: открыть обычное окно**.

Быстрая клавиша: `Cmd+Shift+B` — эта задача назначена задачей сборки по умолчанию.

Второй способ: слева нажмите **Run and Debug** (значок ▶ с жуком), выберите **Text2SQL: открыть окно** и нажмите зелёный ▶.

## Что нажимать в окне

1. Слева в поле **Модель** выберите режим.
2. Вверху выберите компанию.
3. Напишите вопрос по-русски или нажмите готовый пример.
4. Нажмите **Найти ответ**.
5. Смотрите обычный ответ и таблицу. SQL находится под кнопкой **Показать SQL и технические детали**.
6. При необходимости нажмите **Скачать результат в CSV**.

## Какой режим модели выбрать

### OpenAI / совместимый API — самый простой для любых вопросов

Выберите `OpenAI / совместимый API`, вставьте API-ключ в левую панель и оставьте предложенные модель и адрес API. Ключ интерфейсом на диск не сохраняется.

### Ollama — открытая локальная модель

Этот вариант соответствует требованию задания об открытых моделях. Сначала нужно отдельно установить Ollama, загрузить модель и запустить её. В интерфейсе выберите Ollama и укажите, например, `qwen2.5-coder:7b`.

### Демо

Работает без ключа, но понимает только 15 готовых примеров. Это проверка интерфейса и баз, а не настоящая языковая модель. Для произвольных вопросов выберите OpenAI или Ollama.

## Как остановить

Закройте окно Text2SQL. Если запускали из VS Code, при необходимости нажмите корзину в панели Terminal. Базы можно оставить запущенными — следующий старт будет быстрее.

Чтобы остановить и базы:

```bash
cd "/Users/pmapmapm/Documents/large larping machine/Text2SQL"
docker compose stop
```

## Если окно не открылось

Откройте Docker Desktop, дождитесь зелёного статуса и снова дважды нажмите `START_TEXT2SQL.command`.

Ручной запуск из Terminal:

```bash
cd "/Users/pmapmapm/Documents/large larping machine/Text2SQL"
./start_app.sh
```

Если всё же нужен браузерный вариант, запустите `START_IN_BROWSER.command` или задачу VS Code **Text2SQL: открыть в браузере**. Скрипт теперь явно открывает адрес [http://localhost:8501](http://localhost:8501).

## Для сдачи и разработки

- CLI: `./run.sh --domain 01_trading_company --question "ваш вопрос"`
- тесты: `.venv/bin/pytest -q solution/tests`
- оценка: `.venv/bin/python solution/evaluate.py --provider ollama`
- submission: `.venv/bin/python solution/create_submission.py --provider ollama --output submission.csv`

Подробности находятся в `solution/README.md`, а краткий сдаваемый отчёт — в `FINAL_REPORT.md`.
